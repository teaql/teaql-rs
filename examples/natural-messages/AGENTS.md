# Natural Checker message example

Use `python3 scripts/verify-natural-messages.py --all-targets --example --output
/new/evidence/path` from the runtime repository. The output path must not exist.

The model and unedited generated library belong to `../context-derived/fixture/`.
Do not read or change that library to discover APIs. Read this application source
and use current model-aware Assist with its `model.xml` when an operation is
missing. The presentation JSON is application-owned passive metadata until the
generator emits the new model resource automatically.

Keep queries bounded with nonempty comment and purpose. Every write uses the
generated audited-save API. Preserve complete-load and Context Fix behavior;
messages must not alter validation or create a new mutation. Never print the
guarded token. The verifier retains compact logs, response JSON and one SQLite
database used twice; it removes only its own build tree after children exit.
