# 5.0.4: governed SQL diagnostics across generated runtimes

This patch aligns TeaQL Rust with the seven-runtime masking contract:

- render copyable SQL diagnostics while masking model-declared business fields;
- keep credentials and unknown metadata fail-closed;
- scrub mutation target identifiers from free-text log intent;
- preserve custom sink failures as non-blocking diagnostics;
- package the shared masking test vector for independent crate tests.

The generated consumer, live SQLite/PostgreSQL/MySQL provider, lint, security,
and seven-language conformance gates passed before this release preparation.
