# TeaQL Rust 8.2.0

Generated models can opt in to compile-time entity identities and field slots
with `teaql_rs_generated_symbols="true"`. Fixed-field mutations and typed row
access can address the shared generated symbol table. Numeric slots are scoped
to one generated model layout. Persisted identities, model field names and SQL
column mappings retain their existing meaning.

The Rust examples use shared generated field descriptors for their fixed model
fields. The School Management example verifies SQLite grouping, its scalar
`school_type_id` result, explicit aliases and related SchoolType details.

This release also updates the URL-encoding dependency pins. Existing generated
clients can keep their published string-keyed ledger API. Regenerate with a
generator that supports the symbol option when adopting the indexed API.

The public crate set follows the existing [release provenance contract](../scripts/verify-release-provenance.sh).
